# 功能驗收

使用測試帳號與可刪除的測試專案執行。自動測試指令見 [自動化驗證](10-e2e-testing.md)；平台設定見 [上線檢查清單](11-release-checklist.md)。

| 項目 | 操作 | 預期結果 |
| --- | --- | --- |
| 首頁 | 操作捲動按鈕、FAQ、註冊入口與 footer，切換手機、深色模式及減少動態設定 | 捲動不改網址、FAQ 可用鍵盤展開、減少動態時不隱藏內容、畫面不橫向溢出 |
| 註冊與驗證 | 註冊帳號，開啟驗證信中的連結 | 驗證完成後可登入；重寄後舊連結失效 |
| 登入與登出 | 登入、重新整理、登出後嘗試開啟專案 | 重新整理仍維持登入，登出後受保護內容不可存取 |
| 密碼重設 | 透過忘記密碼寄送連結並設定新密碼 | 新密碼可登入，舊密碼與舊 session 失效 |
| 個人專案 | 新增專案、更名、刪除空白測試專案 | 列表同步更新，刪除後舊網址不可存取 |
| 節點與連線 | 編輯文字、底色、位置與連線標籤，待儲存後重新整理 | 內容與樣式保留，雙擊節點與連線分別開啟正確編輯介面 |
| 檔案 | 上傳 PNG／PDF，重新整理後下載 | 檔案紀錄保留，下載內容與原檔相符 |
| AI | 設定 Gemini Key，建立資料架構、發散與收斂 | 回覆正常；收斂以發散內容為依據，結果可編輯 |
| 匯出 | 匯出含底色、連線與圖片的畫布 | PDF 分頁可讀；PNG ZIP 分片完整，原畫布不變 |
| 共享權限 | 以 owner、admin、editor、viewer 測試讀寫與成員管理 | 各角色只能執行允許的操作，viewer 無法寫入 |
| 單一專案邀請 | 非工作區成員登入後接受連結，檢查編輯／檢視、加入期限、撤銷及其他專案／檔案 | 僅取得指定專案；到期不再接受新加入，已加入者保留直到撤銷；工作區既有權限保留 |
| 即時共編（啟用服務後） | 兩帳號同改節點／連線／資料池、同開一個編輯視窗儲存文字、斷線重連、全部關頁後重開 | 內容合併且一致，已同步內容保存；同時選擇不同位置／底色得到一致結果，不能同時保存兩個值 |
| 共編撤權 | 對正在連線的 editor 降權、移除成員或停權，再嘗試寫入 | 雲端房間 ACL 已撤銷或降為唯讀，不只是隱藏介面按鈕；見共編指南的真實服務驗收 |
| 自動備份（啟用後） | 修改測試畫布後確認 Webhook 交付，重新整理備份清單；再試立即備份 | 各有新增時間紀錄，失敗會顯示錯誤；viewer／editor 不可操作 |
| 備份還原 | 還原包含三區、底色、連線文字、對話與附件的版本，核對並關頁重開 | 另建新專案，原畫布不變；附件可下載；缺檔或損壞資料會停止還原 |
| 雙分頁衝突 | 同一專案開兩個分頁，先後修改同一版本 | 過期版本被拒絕，不覆寫較新的內容 |
| 離線重試 | 離線修改後恢復連線，重試儲存並重新整理 | 顯示未儲存狀態，重試成功後資料保留 |
| 系統管理員 | 查看帳號管理、調整測試帳號狀態與角色 | 一般使用者不可存取管理 API；不能停權自己或移除最後一位啟用管理員 |

真實 Neon 持久化測試需另外執行 `pnpm test:db`，使用可丟棄的獨立分支。記憶體模式或單純重新整理成功，不能代替跨程序資料還原測試。

驗收記錄應包含版本、日期、執行環境及失敗步驟。截圖與日誌須遮蔽帳號個資、憑證與含 token 的網址。
