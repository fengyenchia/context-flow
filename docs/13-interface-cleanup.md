# 介面與目錄清理

更新日期：2026-10-24。

## 介面原則

- 保留頁面標題、操作名稱、使用者內容與必要狀態，不再加入裝飾性英文副標、口號或重複介紹。
- 保留欄位限制、Email 驗證、權限、刪除警告和錯誤提示，不以精簡為由移除操作所需資訊。
- 沿用原本配色、按鈕和自訂 tooltip，不更動資料格式或資料庫。

## 已調整

- 首頁：縮短介紹，移除英文眉題、背景光暈和重複功能介紹。
- 登入／註冊／重設密碼：共用單欄表單，移除側欄宣傳、英文口號；保留驗證與重設步驟。
- 導覽：移除品牌英文副標；帳號列維持純資訊，沒有假選單箭頭或 hover 底色。
- 工作區：標題統一「工作區」，移除英文與介紹，簡化新增對話框。
- 設定／帳號管理：移除重複頁首說明，保留金鑰測試、密碼重設及權限資訊。
- 畫布：移除各區英文副標、空白對話口號和節點編輯重複提示。區域改用明確 `area` 識別，對話標頭使用 `data-conversation-header`，功能不依賴英文顯示文字。

## 清理範圍

- 移除 33 個空資料夾，包括未使用的舊 `backend/src/modules`、`common`、`jobs`、`config`、前端 API 佔位路徑及空的功能／元件目錄。只刪除檢查當下為空的目錄，未刪除資料檔。
- 移除未使用的 `backend/oxlint.json`；實際 lint 指令使用 ESLint，專案沒有 Oxlint 相依或引用。
- 保留環境設定、migration、測試、品牌原始素材與文件。
- 保留 `node_modules`、套件存放區、`node_modules_acl_backup`、建置快取與驗收輸出；它們不是未使用的程式碼，可能仍被執行中的服務、套件連結或驗收追蹤使用，不任意遞迴刪除。

空資料夾可隨時重新建立；刪除的 Oxlint 設定可由 Git 還原。沒有變更 production `DATABASE_URL` 或執行 migration。
