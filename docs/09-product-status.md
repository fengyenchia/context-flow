# ContextFlow 功能盤點與開發狀態

本文件依目前 Next.js 前後端的有效程式盤點；舊 NestJS 原始碼與設計草稿不視為已接線功能。

## 目前版本已實作

- 帳號：註冊、Email 驗證與重寄、登入、登出、密碼重設、修改密碼及帳號管理。
- 安全：scrypt、Access JWT、HttpOnly refresh cookie、refresh 輪替與同時請求合併、每個後端實例的驗證操作限流。正式環境缺少資料庫、登入密鑰或寄信設定時不假裝成功。
- 工作區：個人與共享工作區、邀請接受/拒絕、成員清單、角色修改、移除及離開工作區；擁有者受保護。
- 工作區互動：查看成員、邀請、新增工作區、新增/編輯/刪除專案使用統一視窗，搭配背景遮罩、標題、關閉與 Esc、鍵盤焦點循環及返回觸發按鈕。成員讀取立即顯示載入，錯誤可在視窗內重試，角色使用中文；成員與邀請按鈕集中於工作區標頭。
- 專案：建立、列表、編輯名稱/說明、輸入名稱二次確認刪除。
- 畫布：資料池與三區節點、連線、顏色、拖曳、階層排版、節點內容編輯；新增位置會避開既有節點。
- AI：Gemini BYOK、對話、發散節點與收斂總結。收斂以發散節點完整內容、關係及重要標記為主，資料架構僅作背景；要求路線列出來源標題與 ID，不再混入原始資料池重新發想。來源正確性與 AI 輸出仍需人工確認。需要有效 API Key，沒有自動檢索文件。
- 保存：只寫本次變更；Neon HTTP batch 在交易內完成。讀取不重寫全庫，儲存失敗回報 503 並還原請求狀態。
- 畫布衝突：保存版本檢查、資料庫交易鎖與 revision 檢查；舊視窗收到 409，不會直接覆蓋新版本。畫布顯示儲存狀態、失敗重試及衝突提示。
- Email 驗證 token、密碼重設 token、session、憑證與畫布資料均有正規化資料表。訊息依 sequence 還原。
- 檔案：R2 預簽上傳、20 MB 限制、實際大小確認、pending/ready 狀態及授權下載原始檔。需完成 R2 設定後才能使用。
- 匯出：只保留同一組 PDF、PNG 按鈕與自訂 tooltip。以不影響編輯畫布的副本輸出資料池與三區，依世界座標計算大小，包含負座標。大圖以原始比例分片，相鄰片重疊 320px；PNG 圖片包成 ZIP，PDF 以 A4 橫式分頁列印，不再將三區全部縮成一頁。匯出前需展開三區。
- 圖片節點：本機圖片保存實際內容而非暫存 `blob:` 網址，重新整理後仍可讀取。匯出遇到失效或損壞圖片時，在副本標示缺圖並顯示警告，不中斷其餘內容；PNG ZIP 另附圖片警告。舊資料若只剩失效暫存網址，必須重新上傳原圖，程式無法還原已遺失的圖片內容。
- 測試：單元測試、API 流程整合、Chromium 主流程，以及獨立測試資料庫的完整快照還原/交易回滾/衝突測試程式。

## 最新驗收狀態（2026-10-24）

依使用者提供的終端機結果，專用 Neon 測試連線隔離檢查及 `pnpm test:db` 已通過（1 項主測試通過、1 項 probe 在父程序依設計跳過並由子程序執行），包含跨程序還原、舊版本拒絕與原子回滾。使用者另確認 PDF／PNG 實際下載與內容、重新整理後資料保留、Gemini 實際生成、郵件實際收信及 R2 檔案保存成功。證據與驗收邊界見 [驗收報告](12-acceptance-report.md)。

## 仍需部署設定或進階人工抽查

Production Neon 已於 2026-10-23 使用原本 DATABASE_URL 套用到 0004，並驗證 Email token 表與既有表筆數；這一項已完成，不需重做。其他環境仍需自行 migration。production 先前已套用的 0003 與本機封存版 hash 不同，本次未重跑或改寫歷史；應用程式不再讀寫 app_state。

1. Vercel 兩個 Project、自訂網域與環境變數；部署後執行人工驗收，平台 WAF/rate limit 另需設定。本機驗收不等同正式網址驗收。
2. 如需完整郵件情境覆蓋，再抽查重寄、忘記密碼與舊連結失效；目前回報確認的是實際收信成功。
3. Gemini 基本生成已確認；不同內容的收斂來源、語意品質及配額邊界仍需持續觀察。
4. R2 基本檔案保存已確認；正式網域的 CORS 與金鑰最小權限於部署時核對。刪除專案會移除檔案紀錄，不會自行清空 R2 物件。

具體步驟見 [上線前操作清單](11-release-checklist.md)。自動測試設定完成不等於已驗證實際雲端服務。

## 明確不在目前版本範圍

- RAG、Embedding、文件解析與來源檢索：依目前決定暫緩。
- 節點群組：依目前決定移除，不應重新加入。
- Markdown、JSON、SVG 匯出：目前不提供。ZIP 僅為 PNG 分區圖片的下載容器，不是額外格式按鈕。

## 後續擴充，尚未實作

- Liveblocks 即時節點/連線同步、Presence 與游標。共享工作區目前提供權限與共同存取，並以版本衝突保護輪流編輯，不能當成即時多人共編。
- 專案複製、版本歷史、復原/重做、永久 audit log。
- 影片節點、程式碼語法高亮、圖片 Lightbox、標籤篩選。
- 收斂結果的語意差異合併與去重；目前增量提示不等於保證自動合併。
- 新手導覽與完整元件/API 參考文件。

這些是擴充項目，不是填入雲端金鑰就會自動出現的既有功能。
