# 功能現況

更新：2026-10-24。依有效程式與使用者回報整理；原始草稿不代表已實作。

## 已實作

- 帳號、Email 驗證／重寄、登入登出、密碼重設、管理員帳號狀態／角色。
- 個人／共享工作區、邀請接受／拒絕、成員角色與移除／離開；專案新增／編輯／確認刪除。
- 資料池與三區畫布、節點內容／底色／位置、手動連線與文字、自動排版。
- Gemini BYOK、對話轉節點、資料架構與依發散內容收斂，結果需人工確認。
- Neon 正規化保存、跨程序還原、交易回滾、畫布過期版本拒絕、離線重試。
- R2 私人原始檔上傳／完成確認／授權下載；本機圖片節點保存實際內容。
- PDF 分頁與 PNG 分片 ZIP；包含負座標、底色、連線與缺圖提示。
- 工作區 modal、焦點／Esc、載入與錯誤重試；介面已移除裝飾性英文與重複提示。
- 本機單元、API、瀏覽器、密鑰與專用 DB 測試入口。

## 已確認與未確認

使用者已回報前後端 Vercel Ready、正式網域與 health、正式 R2 CORS 修正及上傳成功，並完成登入／重載、節點與連線、匯出、AI、檔案、共享權限、雙分頁衝突、離線重試及郵件／密碼重設驗收。屬人工回報，不等同本輪代理重新操作正式站。詳見 [驗收報告](12-acceptance-report.md)。

目前待確認的是平台 WAF／限流、R2 私有與最小權限、Preview secrets 隔離、匿名訪客不被平台登入攔截、空白專案更名／刪除，以及維運備份／通知。不要再將已完成部署或測試連線列為未設定。

## 已知限制

- 共享工作區提供共同存取與衝突拒絕，不是即時多人共編，不自動合併變更。
- 現有驗證限流為每個程序計數，不是跨實例／全球持久計數；平台設定見 [防護指南](15-backend-security.md)。
- 檔案保存不等於 PDF 解析或文件檢索；刪除專案不自動清除 R2 原始物件。
- 舊資料只有失效 blob URL 時，須重新上傳；加密 key 沒有內建版本輪替工具。
- health 只檢查設定存在，不驗證所有外部服務。
