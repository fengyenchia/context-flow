# 功能與限制

## 功能

- 帳號註冊、Email 驗證／重寄、登入登出、密碼重設與系統帳號管理。
- 個人／共享工作區、成員邀請、角色權限與專案管理。
- React Joyride 新手教學：新註冊帳號分段認識工作區與畫布，支援上一步、跳過及重新播放。
- 資料池與三區畫布、節點內容／底色／位置、連線文字及自動排版。
- Gemini 個人 API Key、對話轉節點、資料架構生成與發散內容收斂。
- Neon 資料保存、畫布版本衝突檢查與離線重試。
- R2 私人檔案上傳、完成確認與授權下載。
- PDF 分頁匯出與 PNG 分片 ZIP 匯出。

## 限制

- 即時共編需完成 [Liveblocks 設定](16-realtime-collaboration.md)；未啟用時仍採版本衝突保護。單一專案邀請連結、遠端游標及離線重整復原尚未提供。
- 啟用共編後，最新畫布保存在 Liveblocks，Neon 舊畫布不是最新備份；尚無停用服務後的自動遷回工具。
- 教學完成狀態依帳號記在註冊時的瀏覽器，不跨裝置同步；既有帳號可手動開啟教學，不會自動彈出。
- AI 生成內容需人工核對；可用模型與配額依使用者 API Key 而定。
- 檔案僅供保存與下載，不提供文件解析、Embedding 或 RAG 檢索。
- 刪除專案不會自動清除 R2 原始物件，需另行管理孤立檔案。
- 僅保存失效 `blob:` 網址的舊圖片，需重新上傳。
- API Key 加密金鑰尚無自動輪替工具，更換前需規劃資料重加密。
- 應用程式登入限流使用每程序記憶體計數；跨實例防護見 [Backend 防護](15-backend-security.md)。
- `/api/health` 回報服務與設定狀態，不代表外部服務均已通過實際讀寫驗證。

測試方式見 [自動化驗證](10-e2e-testing.md)，人工檢查見 [驗收項目](12-acceptance-report.md)。
