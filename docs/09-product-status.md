# 功能與限制

## 功能

- 帳號註冊、Email 驗證／重寄、登入登出、密碼重設與系統帳號管理。
- 個人／共享工作區、成員邀請、角色權限與專案管理。
- 單一專案邀請連結：加入期限、編輯／檢視權限、撤銷與受邀清單；只授予指定專案，不加入工作區。
- React Joyride 新手教學：新註冊帳號分段認識工作區與畫布，支援上一步、跳過及重新播放。
- 資料池與三區畫布、節點內容／底色／位置、連線文字及自動排版。
- Gemini 個人 API Key、對話轉節點、資料架構生成與發散內容收斂。
- Neon 資料保存、畫布版本衝突檢查與離線重試。
- 即時共編可顯示其他在線者名稱及所在區域的游標，位置隨各自視角換算；檢視者也可參與游標顯示。
- R2 私人檔案上傳、完成確認與授權下載。
- 可啟用每日清理已刪除專案的 R2 原始檔：寬限期、即時 Neon 引用核對、分批續跑，保留現存專案與備份副本。
- PDF 分頁匯出與 PNG 分片 ZIP 匯出。
- 可啟用 Liveblocks Webhook 自動備份畫布與附件至獨立私人 R2，owner／admin 可立即備份、瀏覽歷史及還原為新專案，見 [畫布備份](17-canvas-backups.md)。

## 限制

- 即時共編需完成 [Liveblocks 設定](16-realtime-collaboration.md)；未啟用時仍採版本衝突保護。離線重整復原尚未提供。
- 專案邀請需 migration 0005 與 Backend 功能開關，見 [邀請設定](18-project-invitations.md)。期限僅限制加入，既有協作者在撤銷連結後收權；多重授權取聯集。
- 啟用共編後，最新畫布保存在 Liveblocks，Neon 舊畫布不是最新備份；尚無停用服務後的自動遷回工具。
- 畫布備份需另外完成 R2／Webhook 設定；限制與清理另需 Inngest 及保留旗標。啟用後每專案最近 50 份、最長 30 天，自動備份間隔至少 15 分鐘，附件副本經引用檢查才會刪除。已刪除專案須先恢復 Neon 資料，才能透過原專案入口還原。尚未同步的本地修改不包含在內。
- 教學完成狀態依帳號記在註冊時的瀏覽器，不跨裝置同步；既有帳號可手動開啟教學，不會自動彈出。
- AI 生成內容需人工核對；可用模型與配額依使用者 API Key 而定。
- 檔案僅供保存與下載，不提供文件解析、Embedding 或 RAG 檢索。
- 原始檔清理需 Backend `R2_PROJECT_CLEANUP_ENABLED=true` 及 Inngest 同步；未啟用時原檔仍保留。首次確認專案不存在至少 24 小時後才清理；現存專案中已移除的資料池檔案不在此範圍。
- 僅保存失效 `blob:` 網址的舊圖片，需重新上傳。
- API Key 加密金鑰尚無自動輪替工具，更換前需規劃資料重加密。
- 應用程式登入限流使用每程序記憶體計數；跨實例防護見 [Backend 防護](15-backend-security.md)。
- `/api/health` 回報服務與設定狀態，不代表外部服務均已通過實際讀寫驗證。
- Preview 的 API 建置檢查可攔截缺少設定與已知正式 API；完整資源隔離、通知收信與舊憑證撤銷仍須依[維運指南](19-operations.md) 核對，不能由建置成功推定。

測試方式見 [自動化驗證](10-e2e-testing.md)，人工檢查見 [驗收項目](12-acceptance-report.md)。
